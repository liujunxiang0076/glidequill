# GlideQuill（拂标）· Windows 产品需求方案

核心优先评审稿 v0.26 ｜ 2026-11-19

## 当前交付 · 手势导航与实际窗口反馈

打开全局手势，在目标窗口的可见区域按住鼠标右键划动，移动过程中绘制平滑轨迹。匹配到已绑定动作的方向时，在指针所在显示器工作区底部居中显示动作字幕，松开后默认保留 0.55 秒。识别使用原始输入采样。八条直线统归“基础方向”。左、右、上、下默认对应后退、前进、页面顶部、页面底部，四个斜向默认未绑定。每个方向可独立选择动作。鼠标移到已绑定的下拉框时，点 × 可清除该项。四个往返和八个转角分别成组，均默认未绑定。转角支持纵向起笔和横向起笔。往返容许横向错位、圆弧折返和较短回程，转角按连续轨迹识别。设置页用起点和箭头示意整笔画法。「重置」恢复当前分组的默认值。上述修改暂存于窗口，点击「保存并重载」后统一用于下一笔手势。普通右击照常弹出菜单，未匹配的拖动显示“未识别”。后退、前进、页首和页尾已接入实际窗口。以按下右键时指针下的窗口为目标。导航和编辑动作在该窗口获得焦点后发送按键，窗口管理动作直接作用于该窗口。松键时按本笔起始绑定执行一次，停笔超时或切换前台窗口会取消。复制、粘贴、最小化、最大化／还原和关闭也已接入；升级后按已保存的绑定执行。

主窗口通过左侧导航分为常规设置、手势规则、动作列表和轨迹与字幕。各页支持记住启停、登录时自启到托盘、停笔后取消手势（默认 0.5 秒，可关闭）及松键后保留时间（可立即消失）。首次运行默认关闭手势与自启。按需在手势库中录制与试画。四个导航动作支持全部现有手势；20 个手势均支持按程序文件名覆盖。应用与通用规则共用保存按钮，支持逐项继承或单独停用。排除应用和全屏暂停优先。手势库提供另外 16 个图形、录制、自定义快捷键、应用组、迁移预览、规则包导出、回退和恢复。

**交互验收**

- 点击快捷开关或同一行的标签，只切换一次。写入失败时恢复上一个有效状态，就近显示原因。切换主题或启停手势后，手势规则页的未保存草稿继续保留。
- 暂停全局手势时仍可编辑生效范围。重新开启后按已保存的范围工作。修改范围从下一笔手势生效。
- 沿用 940 × 550 逻辑像素的默认内容区，首屏可见五项。缩小可用工作区时允许右侧内容纵向滚动，保留左侧导航。键盘可依次操作控件，返回排除列表的上一级后，焦点回到「排除的应用」。

手势规则页汇总三个分组的未保存项数，改回原值会扣减。「重置本组」只改当前分组的草稿。停笔时长、松键后保留时长归「轨迹与字幕」。右键加滚轮可在手势库绑定。边缘滚动和触发角仍列入可选功能池。

## 1. 核心产品目标

让用户在 Windows 的常用程序里，按住鼠标右键画一个熟悉的手势，就能执行对应操作。新用户可以在一分钟内学会后退；MouseInc 用户可以带着已有的手势形状和常用绑定开始使用。

**首版以“普通右键可靠、常用手势顺手、后台足够轻”作为发布条件。** 建议核心范围止于右键手势、应用规则、基础动作、旧配置迁移和必要的设置。截图整组暂缓。后续功能分别评估，暂不排版本或日期。

## 2. 后续使用场景

- **第一次使用**。解压运行，开启全局手势并在浏览器里向左划；松开右键即可后退，轻点右键照常打开菜单。托盘菜单可以暂停、恢复或退出。
- **从 MouseInc 迁移**。选择旧 JSON，预览哪些手势可以直接使用、哪些依赖后续功能，一次应用；在记事本向上划执行复制，在浏览器画相同手势回到页首。可撤销这次导入。
- **调整一条规则**。在设置中选择程序和手势，绑定快捷键，试画并查看命中结果。练习时只显示会执行的动作。保存后立即生效，可单独停用该规则。

## 3. 后续核心功能与验收

| 核心能力 | 首版行为 | 怎样验收 |
|---|---|---|
| 右键手势 | 支持方向、折线、自定义轨迹；提供录制、命名、试画、启停和删除。可调触发距离、停顿超时、灵敏度和轨迹显示。 | 轻微抖动仍弹一次原生菜单；跨窗口释放仍以起点窗口为目标；超时、取消和低置信度不得执行绑定动作。 |
| 应用规则 | 全局规则作为基础，允许单应用或应用组覆盖；支持排除列表和全屏放行。顺序为暂停／排除、单应用、应用组、通用；同级冲突在保存前提示。 | 同一向上手势分别命中复制和页首；在排除的程序里右键拖放正常；目标窗口关闭时停止派发。 |
| 基础动作 | 支持发送快捷键，以及后退／前进、复制／粘贴、最小化、最大化／还原、关闭当前窗口。内置预设只启用基础导航，关闭窗口等动作由用户绑定。 | 支持编辑快捷键；一次手势最多触发一条绑定；动作取消后释放本次按下的修饰键。 |
| 配置与迁移 | 支持本地配置的导入、导出、校验和恢复。MouseInc 2.13.4 的模板与绑定分别读取，保留顺序和启停状态；多步链只要有一步未支持，整条保留但停用。 | 以本机 36 个模板、22 条通用绑定、13 条应用绑定为样本逐项核对；12 条原本停用的热键不注册。迁移报告列出可用、原已停用、待支持及需审阅项。原文件只读。 |
| 托盘与设置 | 单实例，普通用户权限运行；托盘提供暂停、设置和退出。支持按需自启、恢复上次有效配置；重复启动进入设置。 | 不联网也能安装、练习、编辑和迁移。配置损坏时放行输入并提供恢复；资源管理器重启后托盘入口可找回。 |

**边界示例**。绑定“向上 → Ctrl+C”属于核心，因为这是一次手势发送快捷键；监听全局 Ctrl+C 两次后显示划词菜单属于可选功能。导入一个画框轨迹时可以保存其形状；如果它绑定的是截图，规则显示“待支持”，练习区可试画，桌面上不会误触发其他动作。

## 4. 技术与质量门槛

采用 Rust + Win32，首批验证 Windows 11 x64 和 Windows 10 22H2 x64。轨迹识别、规则匹配和 JSON 迁移可离线回放；系统输入与窗口操作集中在 Windows 适配层。设置窗口按需创建，输入线程只做识别所需的轻量处理。默认不记录输入内容、不发遥测、不自动提权。权限更高或无法可靠定位的窗口优先放行。

| 项目 | 原型验收目标 |
|---|---|
| 常驻开销 | 核心便携压缩包 ≤ 5 MiB；默认空闲私有工作集 ≤ 15 MiB；平均 CPU ≤ 整机 0.1%。四核、8 GB 基准机关闭设置，预热一分钟后采样十分钟。 |
| 响应与识别 | 500 次手势测松键到动作开始，P95 ≤ 30 ms。5 人各画 10 种手势、每种 10 次，正确率目标 ≥ 95%；另测 1,000 次普通右击／轻微抖动，误触发目标为零。 |
| Windows 兼容 | 验证左右键交换、混合 DPI 双屏、负坐标副屏、休眠恢复、锁屏、全屏和排除应用；普通右键和目标窗口定位分别验收。 |
| 发布阻断 | 可复现的吞右键、动作发错窗口、导入破坏原配置、未经授权传出内容，均阻断发布。性能数字为待测目标，发布时附测量结果。 |

## 6. 开发顺序

1. **验证手感**。已在 Chrome 和资源管理器验证四个导航动作；继续按质量门槛测量真实鼠标使用中的误触和响应延迟。
2. **可日用预览**。应用组、录制编辑与旧配置导入预览已接入设置窗口，现可带着已有规则试用。
3. **核心正式版**。按第 3、4 节验收，逐项公布旧配置支持情况；暂缓功能不阻塞发布。
