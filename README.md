# GlideQuill · 拂标

Windows x64 鼠标手势工具，使用 Rust 和 Win32。当前版本用于体验右键划动的轨迹与识别反馈，绑定动作的实际执行留到下一阶段。

## 试用

1. 运行程序，打开「全局手势」。同时使用其他右键手势工具时，先暂停其中一个。
2. 在普通前台窗口按住右键，向一个方向划动。蓝色轨迹随指针平滑绘制。命中方向时，动作名称立即显示在指针所在显示器下方中央，并在松键后按设定时长消失。距离不足或形状不匹配的拖动显示「未识别」。
3. 轻点右键打开原有菜单。按住 Shift 可临时使用原生右键拖动。
4. 关闭设置窗口后可继续在托盘运行。双击托盘图标或再次启动可打开设置；托盘右键菜单可暂停、恢复或退出。

| 基础方向 | 默认动作 |
| --- | --- |
| ← 向左划 | 后退 |
| → 向右划 | 前进 |
| ↑ 向上划 | 页面顶部 |
| ↓ 向下划 | 页面底部 |
| ↖ 左上、↗ 右上、↙ 左下、↘ 右下 | 各自未绑定，可独立选择 |

在「手势规则 → 基础方向」点开任一方向的下拉框，选择导航、复制粘贴或窗口动作。鼠标移到已绑定的下拉框时，点击箭头旁的 × 即可清除该项，也可以用键盘选择「未绑定」。「重置」将八项恢复为默认值。点击「保存并重载」，下一笔手势就会使用新绑定。切换设置页或收起到托盘会保留草稿，退出程序会丢弃未保存的修改。

首次启动时处于暂停状态，以后自动恢复上次启停和外观。按显示器 DPI 绘制，提供浅色和深色主题。[浅色实窗](docs/windows-light.png) · [深色实窗](docs/windows-dark.png)

## 基础设置

左侧「常规设置」管理全局启停、登录自启和外观。「手势规则」管理八个方向的动作绑定。「轨迹与字幕」调整停笔和松键后的保留时间。也可以从规则页或托盘启停手势。

| 设置 | 可选值与效果 |
| --- | --- |
| 登录 Windows 时自启 | 默认关闭。开启后，当前用户登录时以托盘模式启动，沿用上次启停状态。便携程序移动到新目录后，在新位置重新开启。 |
| 停笔后取消手势 | 不取消、0.5 秒（默认）、1 秒、2 秒、3 秒。已经画出轨迹时开始计时，继续移动会重新计时。超时清除整笔，再画需重新按右键。 |
| 松键后保留时间 | 立即消失、0.25 秒、0.55 秒（默认）、1 秒、2 秒。用于设置松键后轨迹和名称一起消失的时间。 |

启停、外观和时间设置即时保存。方向绑定、启停、外观和时间设置保存在 `%LOCALAPPDATA%\GlideQuill\settings.json`。登录自启由当前 Windows 用户的启动项管理。[常规设置实窗](docs/windows-settings.png)

## 运行与兼容

输入线程采样，窗口线程绘制透明、可穿透且不会激活的轨迹窗口。普通右击在松键时回放；全屏、提升权限的前台程序、交换主次键、按住修饰键和排除的程序放行。识别轨迹只在内存中短暂保存。

已有的 `%LOCALAPPDATA%\GlideQuill\rules.json` 保留在原处。本阶段只读取 `excluded` 排除列表。旧通用和浏览器绑定不会覆盖基础方向绑定，也不会被重写。配置读取失败时暂停手势。

## 构建与验证

在 Windows x64 安装 Rust stable 和 MSVC C++ 构建工具，然后运行

```powershell
cargo fmt --check
cargo clippy --locked --all-targets -- -D warnings
cargo test --locked
cargo build --locked --release
.\target\release\glidequill.exe
```

在交互式 Windows 桌面执行以下检查

```powershell
cargo test --locked native_trail -- --ignored
pwsh -File .\scripts\smoke-test.ps1
```

桌面测试在独立前台窗口向输入处理函数提供坐标，检查松键前的实际轨迹像素、浮层穿透、识别提示和清除。冒烟测试使用临时配置，检查八个下拉框、键盘选项与重启回读、主题、托盘、单实例和旧配置保留。
