# GlideQuill · 拂标

Windows x64 鼠标手势工具，使用 Rust 和 Win32。支持右键手势导航。划动时显示轨迹与动作名称，松开右键后向起笔时指针下的窗口发送一次已绑定的动作。

## 试用

1. 运行程序，打开「全局手势」。同时使用其他右键手势工具时，先暂停其中一个。
2. 在目标窗口的可见区域按住右键，向一个方向划动。蓝色轨迹随指针平滑绘制。命中方向时，动作名称立即显示在指针所在显示器下方中央，并在松键后按设定时长消失。切换前台窗口或停笔超时会取消本笔动作。
3. 轻点右键打开原有菜单。按住 Shift 可临时使用原生右键拖动。
4. 关闭设置窗口后可继续在托盘运行。双击托盘图标或再次启动可打开设置；托盘右键菜单可暂停、恢复或退出。

| 基础方向 | 默认动作 |
| --- | --- |
| ← 向左划 | 后退 |
| → 向右划 | 前进 |
| ↑ 向上划 | 页面顶部 |
| ↓ 向下划 | 页面底部 |
| ↖ 左上、↗ 右上、↙ 左下、↘ 右下 | 各自未绑定，可独立选择 |

后退、前进沿用应用自身的历史。执行导航与编辑动作前，GlideQuill 会激活起笔窗口，再发送浏览器后退键／前进键、Home／End 或 Ctrl + C／V。窗口未获得前台焦点时跳过按键。按住右键时仅预览。松开右键后，输入线程立即处理匹配的动作，一笔只执行一次。派发前若已切换窗口或开始新的鼠标操作，该笔动作取消。字幕保留时长只影响显示。页首和页尾遵循焦点控件的 Home／End 行为：浏览器正文滚到顶端或底端，资源管理器文件列表选中首项或末项。将这四个动作重新绑定到其他基础方向或特殊手势，同样可执行。

复制、粘贴由起笔窗口中获得焦点的控件处理。最小化通过 Windows 异步收起起笔时指针下的窗口，支持使用自绘标题栏且带最小化按钮样式的程序。最大化／还原按窗口实际状态切换，再划一次可恢复原位置和大小。关闭窗口时由目标应用处理保存提示。五项均需自行绑定，旧版已保存的预览绑定升级后会实际执行。

在「手势规则 → 基础方向」点击方向名称、图标或下拉框，选择导航、复制粘贴或窗口动作。鼠标移到已绑定的下拉框时，点击箭头旁的 × 即可清除该项，也可以用键盘选择「未绑定」。「重置本组」恢复当前分组的默认值。页脚合计三个分组的改动，改回已保存值后自动扣减。点击「保存并重载」，下一笔手势就会使用新绑定。切换设置页或收起到托盘会保留草稿，退出程序会丢弃未保存的修改。

**为单个程序设置手势**。在「手势规则」右上角展开「通用规则」，选「添加应用…」并选择程序的 .exe。例如给浏览器的向上划绑定「复制」，其他程序仍使用通用的「页面顶部」。每个方向初始显示「跟随通用」及对应动作。选择「未绑定」可仅在这个程序停用该动作，点击 × 或选择「跟随通用」恢复继承。按程序文件名匹配，同名程序共用一套规则。切换范围可继续编辑，最后点击「保存并重载」一次提交全部修改。已排除的应用始终放行原生右键。[应用规则实窗](docs/windows-app-rules.png)

「往返手势」提供上下、下上、左右、右左四种回划。「转角手势」提供八种直角转向，纵向起笔或横向起笔都可识别。圆点代表起笔，箭头代表结束方向。按住右键一笔转弯即可，允许圆弧、横向偏移和较短回程。新增的四个横向起笔转角默认未绑定。旧版 8 项、16 项配置会沿用原有绑定，新版保存为 20 项。[转角手势实窗](docs/windows-special.png)

手动启动或从托盘打开时，窗口在鼠标所在显示器的工作区居中。默认内容区为 940 × 550 个逻辑像素，工作区较小时自动收紧间距。首次启动时处于暂停状态，以后自动恢复上次启停和外观。按显示器 DPI 绘制，提供浅色和深色主题。[浅色实窗](docs/windows-light.png) · [深色实窗](docs/windows-dark.png)

## 手势库与旧配置迁移

打开「手势规则 → 手势库…」。常用的 20 个方向、往返和转角可直接在规则页编辑。库中另有 16 个图形，包含方框、三段折线、字母和数字。新增图形默认未绑定。

- **让两种浏览器共用手势**。在「应用组」填写组名和成员 `msedge.exe, chrome.exe`，点「保存组」。选中该组，给 `WheelSwitchUp` 和 `WheelSwitchDown` 分别绑定上一个和下一个标签页。按住右键滚轮即可切换。单个程序的绑定优先于组，组优先于通用规则。
- **录制自己的手势**。点「录制或试画…」，在框中按住鼠标键一笔画完，输入模板名，点「使用这笔轨迹」。回到手势库选择动作，或输入 `Ctrl+Shift+T` 等组合键，点「设置绑定」。点「返回并保留草稿」，再到规则页点「保存并重载」才会生效。「识别与轨迹」还可以调节触发距离、模板容差或单独隐藏轨迹。
- **从 MouseInc 迁移**。点「导入并预览…」选取 `MouseInc.json`，选择要迁移的范围，逐条核对后保留到草稿。原来停用的绑定、全局热键、脚本和未支持的动作链均保留原条目与原因，可从「查看待支持项…」查阅。源文件只读。
- **导出与撤销**。「导出规则…」保存当前草稿的手势模板、绑定、应用组、识别选项和待支持条目。外观、排除列表和登录自启属于本机设置。「上次保存版本…」先把上一版规则放回草稿，仍需点击「保存并重载」。配置损坏时可在手势库导入规则或取回上一版，确认恢复后原文件会备份到本机配置目录。

## 基础设置

键盘可用 Tab 聚焦侧栏，上下键切换页面；聚焦手势分组后，左右键切换基础、往返和转角分组。

左侧「常规设置」按手势、生效范围、启动与外观分组；较小的窗口可在右侧滚动。「手势规则」管理基础方向和特殊手势的动作绑定。侧栏「动作列表」列出 19 个内置动作及用途，包括刷新、强制刷新、上一个／下一个标签页、新建／关闭／恢复标签页、浏览器主页、Esc 和 Del。

「轨迹与字幕」调整停笔和松键后的保留时间。也可以从规则页或托盘启停手势。

| 设置 | 可选值与效果 |
| --- | --- |
| 全屏时暂停手势 | 默认开启。在全屏窗口中保留原生右键，退出全屏即可恢复。 |
| 排除的应用 | 选择 .exe 后按文件名匹配；添加与移除会暂存，点击「保存」后从下一笔手势起生效。 |
| 窗口外观 | 点击浅色或深色，即刻切换并保存。 |
| 登录 Windows 时自启 | 默认关闭。开启后，当前用户登录时以托盘模式启动，沿用上次启停状态。便携程序移动到新目录后，在新位置重新开启。 |
| 停笔后取消手势 | 不取消、0.5 秒（默认）、1 秒、2 秒、3 秒。已经画出轨迹时开始计时，继续移动会重新计时。超时清除整笔，再画需重新按右键。 |
| 松键后保留时间 | 立即消失、0.25 秒、0.55 秒（默认）、1 秒、2 秒。用于设置松键后轨迹和名称一起消失的时间。 |

启停、外观和时间设置即时保存。方向绑定、启停、外观和时间设置保存在 `%LOCALAPPDATA%\GlideQuill\settings.json`。登录自启由当前 Windows 用户的启动项管理。[常规设置实窗](docs/windows-settings.png)

## 运行与兼容

输入线程采样，窗口线程绘制透明、可穿透且不会激活的轨迹窗口。普通右击在松键时回放；按设置跳过全屏窗口。提升权限的程序、交换主次键、按住修饰键和排除的程序放行。识别轨迹只在内存中短暂保存。

已有的 `%LOCALAPPDATA%\GlideQuill\rules.json` 保留在原处。首次从 `excluded` 读取排除列表；在设置中保存后，改用同目录下独立的 `excluded.json`。旧通用和浏览器绑定不会覆盖基础方向绑定，也不会被重写。配置读取失败时暂停手势。

## 构建与验证

在 Windows x64 安装 Rust stable 和 MSVC C++ 构建工具，然后运行

```powershell
cargo fmt --check
cargo clippy --locked --all-targets -- -D warnings
cargo test --locked
cargo build --locked --release
.\target\release\glidequill.exe
```

在交互式 Windows 桌面执行以下检查

```powershell
cargo test --locked native_trail -- --ignored
cargo test --locked external_browser_actions -- --ignored
pwsh -File .\scripts\smoke-test.ps1
```

桌面测试在独立前台窗口向输入处理函数提供坐标，检查松键前的实际轨迹像素、浮层穿透、识别提示和清除。外部应用回归测试使用临时配置打开普通浏览器窗口，通过 Windows 鼠标钩子分段划动，在半途中保持右键并检查窗口状态，显示动作字幕后再松键。测试检查另一个窗口在前台时的后退和最小化，以及历史导航、网页滚动、复制粘贴事件、关闭窗口，以及两种标题栏样式下的最小化、最大化与还原位置。可通过环境变量 GLIDEQUILL_TEST_BROWSER 指定 Edge 可执行文件。为冒烟测试加上 `-MeasureNavigation`，可测量 30 次从常规设置点击进入手势规则到原生绘制完成的中位数与 P95。冒烟测试使用临时配置，检查八个下拉框、键盘选项与重启回读、主题、托盘、单实例和旧配置保留。
